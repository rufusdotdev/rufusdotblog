<!-- # The Core Box: The Pattern's Quiet Counterpart -->

A pattern shapes the outside of a part. A core box shapes the thing that shapes the inside. Same trade, same shop, same discipline — but a core box gets built to a different set of rules than the pattern sitting next to it on the bench, and mixing those rules up is how you end up with a core that looks fine and still ruins a pour.

Where a pattern gets packed by sand from the outside, a core box gets filled from the inside. Sand goes into the cavity the box forms, packs against every interior wall, and the core comes out carrying the negative of whatever shape that cavity holds. That single difference changes almost everything about how you build the tool. A pattern needs draft so it can be lifted straight up out of the sand. A core box needs draft too, but it also needs to open — split down a parting line, hinged or pinned so both halves pull away from the core without tearing it apart on the way out. A one-piece core box exists, for simple shapes you can pack and dump, but anything with real geometry is coming out of a box that opens like a clamshell.

Then there's venting, and this is the difference that actually costs you a casting if you get it wrong. A core buried inside molten metal has to breathe. The binder in that sand generates gas as the metal's heat hits it, and that gas has to find a way out through the core and into the mold's own vent system — or it finds its way into the casting instead, as a blow hole sitting exactly where a customer's pressure test will find it. Vent placement isn't an afterthought you add if there's room. It's designed into the core box from the start, matched to the core's shape and the way gas actually wants to travel through it.

The core box also has to talk to the pattern, and that conversation happens at the print. Whatever core seat the pattern built in to locate and support the core, the core box has to produce a core that fits it exactly — not close, not "should work," exactly. A core that seats loose in its print drifts during the pour. A core that seats tight enough to crush at the print cracks under the load of the metal filling the mold around it. Both failures trace back to the same root: the pattern and the core box built as if they'd never have to meet.

Nobody outside a pattern shop thinks about the core box. They think about the core, if they think about it at all, and never the tool that made it. That's fine. The core box was never built to be noticed. It was built to disappear into a hollow passage nobody sees, in a part that only works because the box got the geometry right the first time.

The tool that shapes what's invisible doesn't get to be sloppy about it.
